# AegisGrid

AegisGrid is a counter-swarm decision intelligence platform.

It simulates drone swarm scenarios under imperfect sensor detection, then compares a naive response strategy against an optimized AegisGrid strategy.

## Core Idea

The problem is not perfect drone detection.

The real problem is decision-making under uncertainty and limited defensive resources.

## System Pipeline

Scenario Engine
→ Sensor Layer
→ Fusion Layer
→ Intelligence Layer
→ Decision Engine
→ Evaluation Layer
→ Frontend Dashboard

## MVP

- Simulate 100 drones
- Add imperfect sensor detection
- Fuse noisy detections
- Cluster swarm behavior
- Score threats
- Allocate limited resources
- Compare baseline vs AegisGrid
